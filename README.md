## Deployment

### GitHub Pages Setup

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to **main branch / root**
4. Add `CNAME` file with your subdomain (already included)

### Custom Domain (Subdomain)

Add a `CNAME` DNS record in your domain registrar:

```
Type:  CNAME
Name:  portfoliopro
Value: yourgithubusername.github.io
```

Site will be live at `portfoliopro.pramodtidke.in` within minutes.
